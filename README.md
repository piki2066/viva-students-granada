# Viva Students Granada - Umbral

Propuesta académica de rebranding de una residencia de estudiantes. Landing estática y sistema de identidad.

Las fotografías y los datos de las instalaciones proceden de https://kadora.es/residencias/residencia-universitaria-granada/ y pertenecen a sus respectivos titulares. Esta propuesta no representa un cambio de marca comercial anunciado por la residencia.

Tipografías Manrope e Instrument Serif: SIL Open Font License, incluidas en assets/fonts.

Sin formularios de captación ni sistema de reservas propio.
